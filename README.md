# 영어 에세이 첨삭 아틀리에

주제 고르기 → 한국어 초안 → 영어 쓰기 → 첨삭 → 평가 → 여섯 톤 → 인문 확장 → 결과보고서 → 1~4주차 활동지까지
9단계를 한 화면에서 진행하는 영작 첨삭 도구입니다.

- 파일 하나(`index.html`)로 동작하는 정적 웹앱입니다. 서버도 빌드도 필요 없습니다.
- 첨삭·평가·톤 변환·보고서·활동지는 **인터넷 없이도** 기기 안에서 바로 만들어집니다.
- 각 단계의 "AI로 더 정밀하게 (선택)"은 요청문을 복사해 원하는 AI에 붙여넣고 답을 되돌려 넣는 방식입니다.
- 학생이 입력한 글과 기록은 **그 학생의 브라우저에만** 저장됩니다. 서버로 전송되지 않습니다.
- 기록은 CSV로 내려받아 구글 시트에서 열 수 있습니다.

## Vercel 배포

1. https://vercel.com 에 GitHub 계정으로 로그인
2. **Add New… → Project → Import** (또는 이 폴더를 그대로 드래그 업로드)
3. Framework Preset: **Other**, Build Command: 비움, Output Directory: 비움
4. **Deploy** → `https://프로젝트이름.vercel.app` 주소가 생성됩니다

## GitHub Pages로 올릴 때

저장소에 `index.html`을 올리고 Settings → Pages → Branch를 `main` / `root`로 지정하면 됩니다.
